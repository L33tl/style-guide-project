# Терминология и глоссарий

Чтобы избежать путаницы, мы используем следующие термины и названия.

## 1. Элементы интерфейса
Все названия кнопок, меню и разделов пишутся с заглавной буквы и выделяются **полужирным** шрифтом. Название должно в точности совпадать с тем, что написано на экране.

| Правильно | Неправильно | Примечание |
| :--- | :--- | :--- |
| **Настройки** | настройки, Настройка | Всегда с большой буквы и жирным |
| **Вкладка** | таб, страница | Для обозначения вкладок в браузере |
| **Боковая панель** | сайдбар, панелька | Специфический элемент Amigo |
| **Адресная строка** | поисковик, урл | Место, куда вводится адрес сайта |
| **Кнопка «ВКонтакте»** | кнопка вк, иконка вк | Всегда в кавычках-ёлочках |

## 2. Запрещенные слова (Англицизмы и сленг)
В документации для пользователей мы не используем профессиональный жаргон.

| Не используем | Используем |
| :--- | :--- |
| Кликнуть | Нажать |
| Юзер, пользователь | Пользователь (или обращение «Вы») |
| Контент | Содержимое, материалы (или уточняем: видео, картинки, текст) |
| Аккаунт | Профиль, учетная запись |
| Браузер Амиго | Браузер Amigo (латиницей) |
| Гуглить | Искать в интернете |

## 3. Специфические термины Amigo
*   **Лента** — главная страница браузера с новостями и обновлениями.
*   **Мой мир** — внутренняя социальная сеть браузера.
*   **Друзья** — список контактов пользователя.
